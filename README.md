# YouTube Video Downloader

A beginner-friendly Python project that uses the yt-dlp library to download videos from URLs that the user is authorized to download.

## Features

- Download videos from a URL
- Uses the yt-dlp library
- Simple command-line interface
- Beginner-friendly Python project

## Technologies

- Python
- yt-dlp

## How to Use

1. Install yt-dlp:
   ```bash
   pip install yt-dlp
   
2. Run the Python program:
   python youtube_downloader.py
   
3. Enter the video URL when prompted.
   
Learning Purpose

This project was created to practice:
 - External Python libraries
 - User input
 - Dictionaries
 - Context managers
 - Downloading files with Python
 -
